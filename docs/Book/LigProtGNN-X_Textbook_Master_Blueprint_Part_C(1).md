# LigProtGNN-X Textbook Master Blueprint (BGS v1.0)

# Part C — Writing Standards, Pedagogy & Chapter Generation Specification

## Purpose

This specification defines how every chapter shall be written. Every chapter must exhibit a consistent voice, logical progression, notation, formatting, and educational quality.

## Educational Philosophy

Every chapter shall teach each topic from six perspectives:

1. Intuitive
2. Scientific
3. Mathematical
4. Algorithmic
5. Engineering
6. LigProtGNN-X implementation

## Standard Chapter Structure

- Learning Objectives
- Prerequisites
- Historical Context
- Motivation
- Scientific Background
- Key Terminology
- Definitions
- Mathematical Foundations
- Visual Explanations
- Algorithms
- Engineering Notes
- Repository Mapping
- Complexity Analysis
- Experimental Connections
- Advantages
- Limitations
- Future Directions
- Summary
- Key Takeaways
- Exercises
- References

## Writing Standards

- Academic and technically rigorous
- Define terminology before use
- Explain intuition before equations
- Never present implementation without motivation
- Distinguish established science from project contributions
- Maintain consistent notation throughout the textbook

## Mathematics Standards

For every important equation include:

- Variable definitions
- Assumptions
- Derivation
- Intuition
- Computational meaning
- Engineering interpretation
- Project relevance
- Limitations

## Figure Standards

Every figure shall include:

- Figure number
- Caption
- Purpose
- Discussion in text
- Cross-reference

Preferred figures include architectures, pipelines, workflows, biological schematics, graph representations, attention mechanisms, reliability plots and explainability diagrams.

## Table Standards

Tables should summarize:

- Datasets
- Models
- Hyperparameters
- Metrics
- Experimental results
- Comparisons
- Advantages and limitations

## Repository Integration

Whenever applicable connect concepts to:

- Folder
- Package
- Module
- Class
- Function
- Configuration
- Experiment
- Report

## Educational Callouts

Use:

- Definition
- Example
- Observation
- Engineering Note
- Repository Note
- Research Insight
- Historical Note
- Common Pitfall
- Best Practice
- Open Research Question

## Exercises

Each chapter should contain:

- Conceptual
- Mathematical
- Programming
- Repository exploration
- Research-oriented exercises

## Editorial Rules

Maintain consistency of:

- notation
- terminology
- capitalization
- abbreviations
- numbering
- references
- formatting

## Continuation Rules

- Never regenerate completed chapters unless requested.
- Preserve numbering.
- Preserve notation.
- Preserve cross references.
- Record progress after every generation.

## Quality Checklist

Before accepting a chapter verify:

- Technical correctness
- Mathematical correctness
- Repository consistency
- Figure and table references
- Clear learning objectives
- Appropriate exercises
- Complete references
